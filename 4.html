Table

A tag table é utilizada para definição de tabela no HTML, internamente em uma tabela podemos criar linhas "rows" utilizando a tag <tr> e celulas dentro
das linhas utilizando a tag <td> exemplo:

        <table>
            <tr>
                <td> Celula 1x1 </td> <td> Celula 1x2 </td>
            <tr>
            <tr> 
                <td> Celula 2x1 </td> <td> Celula 2x2 </td>
            <tr>
